# ИС "Каршеринг"

## Бизнес-цель

**Автоматизация краткосрочной аренды автомобилей**: учет автопарка, бронирования и поездок, тарификация.

**Роли**: Клиент, Технический специалист, Администратор автопарка.

**Ключевые сущности**: Автомобиль (гос. номер, статус), Модель/Класс, Парковочная зона, Клиент, Бронь, Поездка, Тариф, Уровень лояльности.

## Бизнес-правила

- Бронь резервирует автомобиль на 15 минут, после чего автоматически снимается.
- Стоимость поездки зависит от класса автомобиля и тарифа (поминутный, почасовой, суточный).
- Постоянным клиентам предоставляется скидка, размер которой зависит от числа поездок.
- У клиента может быть только одна активная бронь.

## Функциональные требования

- Учет автопарка с контролем статуса автомобилей (свободен / забронирован / в аренде / на ТО).
- Модуль бронирования с автоматическим таймером и поиском автомобилей по фильтрам (класс, модель, парковочная зона).
- Оформление поездки и автоматический расчет стоимости с учетом тарифа и скидки.
- Аналитика поездок и выручки за день/неделю/месяц/год.
